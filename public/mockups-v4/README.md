# OpenHub source workspace concept 04

This is a standalone visual mockup. It does not replace or modify the production repository reader.

The direction keeps a few proven source browsing patterns:

- repository identity and current ref stay visible before the source;
- the file tree and reader are separate, scannable surfaces;
- line numbers, file path, commit ref, and source actions remain close to the code;
- context is progressive disclosure, so metadata never takes over the reader;
- folder and file navigation can update the reader in place, with a persistent mobile explorer control;
- mobile controls are icon-first and respect safe-area spacing.

The visual system is intentionally OpenHub-specific: warm paper, ink surfaces, ember accents, a narrow icon rail, quiet hairline dividers, and a source reader that feels like a workbench rather than a provider clone.

Open `/mockups-v4/` in the deployed app or serve this directory as static files. The ref picker, context drawer, mobile explorer, mode tabs, command menu, and in-place file switching are interactive demonstrations.
